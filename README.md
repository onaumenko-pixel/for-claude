# Pipedrive → Google Sheets Export

Google Apps Script для еженедельной выгрузки выполненных активностей операторов колл-центра из Pipedrive в Google Таблицу.

---

## Быстрый старт

### 1. Добавить скрипт в Google Таблицу

1. Откройте нужную Google Таблицу.
2. **Расширения → Apps Script**.
3. Удалите содержимое редактора, вставьте весь код из `pipedrive_export.gs`.
4. Сохраните (`Ctrl+S`).

### 2. Задать параметры (Script Properties — рекомендуется)

Вместо хардкода токена используйте переменные окружения скрипта:

1. В редакторе Apps Script: **Project Settings → Script Properties → Add script property**.
2. Добавьте два свойства:

| Property         | Value                              |
|------------------|------------------------------------|
| `PIPEDRIVE_TOKEN` | ваш API-токен Pipedrive            |
| `SPREADSHEET_ID` | ID Google Таблицы из URL           |

> ID таблицы — часть URL между `/d/` и `/edit`: `https://docs.google.com/spreadsheets/d/<ID>/edit`

Если не хотите использовать Script Properties, замените значения напрямую в секции `CONFIG` в коде.

### 3. Первая ручная выгрузка (09.03.2026 – 15.03.2026)

В редакторе Apps Script выберите функцию `exportFirstWeekManual` и нажмите **▶ Выполнить**.

При первом запуске скрипт запросит разрешения — подтвердите.

### 4. Настроить автоматический триггер

Выберите функцию `createWeeklyTrigger` и нажмите **▶ Выполнить**.

После этого скрипт будет автоматически запускаться **каждый понедельник в 09:00** и выгружать данные за прошлую неделю (пн–вс).

| # | Колонка       | Источник                          |
|---|---------------|-----------------------------------|
| 1 | Тема          | `subject`                         |

## Логика работы

- **Дедупликация**: перед добавлением скрипт считывает все существующие ID из скрытой колонки «Идентификатор» и пропускает уже записанные строки.
- **Фильтрация по дате**: используется поле `marked_as_done_time`, а не дата планирования.
- **Фильтрация по операторам**: приставка «Оператор» удаляется, затем проверяется точное совпадение с именем из списка.
- **Очистка типов**: перед сравнением из `type_name` удаляются все эмодзи (🔥, ✉️ и др.).
- **Пагинация**: выгружает все записи за период, обходя лимит API в 500 записей на запрос.
